# SUMO public evidence index

The [reproduction index](reproduction.json) and [runtime/source receipt](runtime.json)
bind the final executing backend to `a3f857ca1ae2d3689749fc71ad7b8d8a0990adaf`.
Collection, review, CI and documentation commits after it do not create new
model runs or transfer qualification. [Findings](../findings.md) explain the
municipal question and scientific limits; [the guide](../README.md) repeats it.

- Each city directory contains the source harvest manifest, full baseline/works
  scheduled-vehicle/cohort CSVs, native statistics and warning logs, comparison
  CSV/JSON, map and native/stdio check receipt. Every published native artifact
  is hash-bound by `native-mcp.json`. There are 80/73 successful checks, not
  merely a tools/list result.
- [Four host observations](agents.json) link complete public tool payloads,
  immutable observed answers, launch/process receipts and computational reviews.
  All 13 tool families, full source/comparison page chains, native-equivalent
  artifacts and exact typed answer claims pass. Returned PNG receipts do not
  establish agent visual inspection.
- [Manual prose review](narrative-review.json) binds the actual answer bytes:
  both Codex briefs pass; both Hermes briefs fail facts and length. Preserve
  rejected arguments, host-circuit failures/recovery and unsupported claims.
- [Original-method audit](upstream-audit.json) has seven isolated synthetic/source
  checks. Alternative AgentSUMO/legacy full MCP servers were not installed or
  executed as municipal cases. Original XRDS functions are actually executed
  against native SUMO in both final suites.
- [Production live acquisition](live-mcp.json) separately verifies both cities
  through actual CLI and MCP. All source hashes and prepared route/schedule
  bytes match the snapshot experiment; distinct live request manifests are
  preserved. These are data-interface checks, not fresh simulations/LLM runs.
- [Compatibility](compatibility.json) records distinct prototype baseline probes
  under native 1.19 and 1.28. They do not replace final 1.28 results. Matched
  1.19 bindings were not tested. The remaining conflicts/teleports/collision
  prevent calling the downgrade a model repair.
- [Development failures](development-failures.json) retain fixes and unresolved
  limits. `initial-observations/` preserves Codex Bologna V1 at `eaa10aa`, before
  the empty-config/projection packaging corrections. It is superseded by fresh
  final source-bound observations and is not counted as a third city/person.

Bulk tripinfo/FCD/native caches and complete private host events/databases stay
in ignored workspaces. Public export utilities explicitly reject unrelated tool
use and omit reasoning, system prompts, configuration and credentials. Original
permitted inputs/licenses are in the [hash-locked data prerelease](https://github.com/polisplexity/urban-mcp/releases/tag/data-sumo-20261110).

All observations were operated by the original team. Independent-person
[third-city qualification](../../../docs/product-qualification.md) and
[issue #44](https://github.com/polisplexity/urban-mcp/issues/44) remain pending.
Native model-quality problems stay visible and `forecast_admitted=false`.
