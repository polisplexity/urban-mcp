# Odense historical SWMM case

Follow the [shared two-city reproduction guide](../two-city-swmm/README.md), [findings](../two-city-swmm/findings.md) and [case contract](case.json).

This is the original-team computational experiment for Bellinge combined-sewer study network, Odense, Denmark; original published model, approximately 1.7 km2 study area. It does not cover an entire municipal territory or establish current field calibration. Final-product qualification remains pending independent third-city acceptance in [issue #46](https://github.com/polisplexity/urban-mcp/issues/46).
