# Roadmap by evidence

The [master test record](../MASTER_TEST_RECORD.md) is the current status source. The Helsinki inventory established source harvesting, native geospatial operations, MCP and two-host reproduction. The Helsinki/Amsterdam walking case tests transfer, real network distances and a declared link disruption. Every additional capability must earn its own admission.

| Milestone | Reviewable deliverable | Acceptance |
| --- | --- | --- |
| M0: contracts | Tool/data/interface research, public tasks and scope | Review duplication, rights, input gaps and metadata CI |
| M1: municipal data | Question, boundary, exact assets, preparation and binding | Reproducible harvest/snapshot, hashes and meaningful missing/invalid-data checks |
| M2: native sandbox | Pinned container, source inputs and separate outputs | Native baseline, repeat, failure and recovery evidence |
| M3: MCP | Original server reuse or justified missing adapter | Same municipal answers/artifacts through real protocol calls; all exposed operations checked |
| M4: agent operation | Client-neutral runbook, bounded tools and blind task | Independent host completes the case and recognizes limitations without expected answers |
| M5: municipal acceptance | Public evidence dossier and useful bounded finding | Native/MCP/host comparison and independent reproduction; synthetic fixtures are insufficient |
| M6: transfer | Another city, source or tool family | New inputs/rights/operations tested explicitly; no inherited blanket readiness |

A contributor can take a bounded source, function, case or reproduction task without owning a whole family.
